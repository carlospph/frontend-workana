**# 📱 Tela de Login Moderna com Tailwind CSS

Este é um projeto de uma interface de login responsiva, limpa e moderna, desenvolvida para praticar o uso do framework **Tailwind CSS** e a integração de ícones externos.

## 🚀 Tecnologias Utilizadas

* **HTML5**: Estrutura semântica do projeto.
* **Tailwind CSS**: Estilização rápida e responsiva via CDN.
* **Font Awesome**: Ícones de redes sociais (Facebook e Apple).
* **Google Assets**: Logotipo oficial do Google para o botão de autenticação.

## ✨ Funcionalidades

* **Design Responsivo**: A interface se ajusta conforme o tamanho da tela, mantendo uma largura máxima de 450px para melhor legibilidade em desktops.
* **Input Styling**: Campos de entrada com bordas arredondadas e espaçamento interno confortável.
* **Divider Personalizado**: Linha horizontal com o texto "ou" centralizado, criada inteiramente com utilitários Flexbox do Tailwind.
* **Botões Sociais**: Botões de login social com ícones alinhados e cores oficiais das marcas.

## 📸 Prévia

A interface contém:
1. Logotipo centralizado.
2. Campos de E-mail e Senha.
3. Botão de Login principal com destaque azul.
4. Divisor visual.
5. Opções de login social (Facebook, Google e Apple).

## 🛠️ Como executar o projeto

Como o projeto utiliza Tailwind CSS via CDN e Font Awesome via CDN, você não precisa instalar nada. 

1. Faça o download do arquivo `index.html`.
2. Abra o arquivo em qualquer navegador (Chrome, Firefox, Edge, etc.).
3. Ou utilize a extensão **Live Server** no VS Code para visualizar em tempo real.
